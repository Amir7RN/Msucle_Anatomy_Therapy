Live remote call example (WebRTC + TURN + LowerLimbTracker)

Full reference integration: two browsers connect peer-to-peer over WebRTC (TURN-relayed when needed), and the HOST runs LowerLimbTracker against the CLIENT's incoming video. Read this file's <script> and the README's "Building a live remote call" section together — this page is the concrete version of that walkthrough. Requires node signaling-server.js running (see this folder's package.json) and npm run build having produced dist/lower-limb-tracker.esm.js in the package root.
